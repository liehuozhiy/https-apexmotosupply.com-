## 2. 重点风险结论

1. **300 cc 无独立来源字段。** H300 Excel 的 22 个字段没有排量；`300` 仅出现在车型名 H300、JSON 的 `Displacement class` 及 D1 的 `300 class` 派生文案中。D1 没有附加上游来源，车型名也不能自动证明实际排量为 300 cc。
2. **扭矩标签异常。** W1 `Field Matrix!F265:G265`（原始表 `H300!A21:B21`）为 `Maximum power / 27N.m`。单位表明值像扭矩，但标签写成最大功率；下一行 `A22:B22` 又是 `Maximum power / 21Kw`。在来源负责人确认前，`27 N·m` 只能作为“疑似扭矩值”Pending。
3. **启动/电池标签异常。** W1 `Field Matrix!F267:G267`（原始表 `H300!A23:B23`）为 `Mode / 2A Li-ion Battery`。JSON 将其解释为 `Starting battery / 2 A lithium-ion battery`；数值可追溯，但字段语义未经原始表确认。
4. **第四亮点只有部分图像支持。** 现有 H300 身份图和当前第 4 亮点图能看见高位布置的排气及后减震；Excel 只列后减震长度，不列排气，也没有任何“durable off-road riding”耐久性依据。图像外观不能证明耐久性能。
5. **官网来源声明不成立。** 页面描述中的 `official wholesale specifications` 以及技术副标题 `Official website data first...` 与当前“无 H300 官网映射”的事实冲突。

# P01 产品世界预览图门禁审计

日期：2026-08-02
范围：只读审计 `frontend/assets/img/product-world-previews/**` 的 27 个当前映射资产、既有 D/H 审计及 `frontend/assets/js/main.js`。本报告没有修改图片、代码、数据或映射。

## 基准与判定方法

- 基准为当前映射的 `f4-preview-headlight-centered-v6.png`（941 × 1672；SHA-256 `32f5d104f7d7dd4aca7cae37beac18ab95072725ba5c8b5497c7191316fec672`）。`styles.css` 对 F4 另有 `scale(1.15)`，因此它是现行菜单中的**实显构图基准**，而不是要求所有源图采用相同像素尺寸。
- 统一整改目标：源图仍为无字竖版；在现有卡片 `object-fit: cover` 和 HTML 文字层下，完整车辆宜占画布中下部约 62–74% 高、车把横向约 72–84%，顶部保留约 18–23% 的无字安全区。不得用 CSS 放大来掩盖源图主体过小；需整改时创建新版本资产。
- “可点亮”只表示现有身份锚点明确存在同位置灯具，允许在**不改变外形、位置、数量和面罩**的前提下点亮。`无灯` 或 `标配无灯/仅可选` 不得为了统一视觉虚构发光灯具。
- 下表的“需调整”是面向下一批图片制作的门禁结论；不是让前端用共享 CSS 批量缩放。所有路径均为建议的新版本路径，现有版本必须保留。

## 汇总与实施边界

- **无需调整：**F4、Babey、ER3、ER7、ET 2024、ET5、ET7、F9、HS85、SY300（10 款）。
- **需要制作新版本：**Babey+、Bumblebee、ER5、ES11、ET、ET 2022、ET3、ET9、F4+、F29、F29R、H300、S300、S300R、SJ250、SJ300、SN300（17 款）。
- 17 款中允许在现有灯位点亮：Babey+、Bumblebee、ET、ET 2022、F29、F29R、H300、S300R、SJ250、SJ300；S300 待型号级灯具证据。ER5、ES11、ET3、ET9、F4+、SN300 均不得点灯。
- 本审计不构成授权生成、替换或接入。后续每次只处理一个车型版本化资产；不得改动车型 JSON、`site-data.js`、`source-audit-index.json` 或共享 CSS/JS，且须在生成后复核身份、哈希、1440 悬停与 HTML 文字安全区。

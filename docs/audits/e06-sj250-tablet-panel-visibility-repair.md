# E06 SJ250 平板 Panel 背景可见性修复

日期：2026-08-02

## 后续诊断

E05 修复路径后，用户在约 1000px 宽度下仍未看到右上 Panel 的车型图。该宽度命中 `48.01rem–65rem` 的平板范围。通用响应式规则将 Panel `::before` 的图片层设为 `opacity:.24`，并叠加两层深色渐变；SJ250 Panel 原图本身为暗黑红工业图，因此画面视觉上近乎消失。

## 最小修复

在 `frontend/assets/css/product-detail.css` 增加仅适用于 `body.model-sj250.product-detail-page` 的平板断点规则：

- 图片层不透明度从 `.24` 提升至 `.64`；
- 降低两层遮罩强度；
- 保持既有图片位置和尺寸；
- 不影响其他车型、桌面断点或 768px 以下手机断点。

## 验证

- SJ250 Panel 图片文件已目视核对：完整暗黑工业场景、红色背光和车型主体均存在。
- 专用规则位于通用响应式规则之后，选择器含 `body.model-sj250.product-detail-page`，在目标平板范围内覆盖通用 `.24` 不透明度。
- `git diff --check` 通过。

请使用强制刷新后重新打开本地 SJ250 页面确认。内置浏览器仍不能执行该本地可视化复验。

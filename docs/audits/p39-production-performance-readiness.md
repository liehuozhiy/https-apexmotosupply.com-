## 实施内容

1. 首页移除独立的首屏视频 preload 声明，继续由视频元素以 `preload="metadata"` 加载；首屏播放和重播逻辑不变。
2. 首页首屏之后的六张车型图加入原生懒加载和异步解码。
3. 27 个车型页的默认主图加入 `fetchpriority="high"` 和异步解码。
4. 五张图库缩略图加入低优先级、原生懒加载和异步解码；四张核心亮点图及询盘横幅加入原生懒加载和异步解码。
